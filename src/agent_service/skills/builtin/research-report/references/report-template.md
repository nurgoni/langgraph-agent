# Report template

## Question
One sentence restating what the user wants to know.

## Key findings
Three to five bullet points, most important first. Each bullet ends with its source link.

## Details
Short paragraphs that support the findings. Use a table for comparisons.

## Open questions
What the sources do not answer or disagree on. Write "None" if there are none.

## Sources
Numbered list of every link used, with its title.
